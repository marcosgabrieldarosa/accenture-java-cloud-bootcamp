# Módulo 02 – Introdução ao Java e Fundamentos da Linguagem

Este módulo faz parte do **Bootcamp Accenture – Desenvolvimento Java & Cloud (DIO)** e tem como objetivo consolidar as bases da linguagem Java e do ambiente de desenvolvimento.

Aqui foram estudados os conceitos essenciais que sustentam o desenvolvimento backend com Java, preparando o terreno para Programação Orientada a Objetos, Spring Boot e aplicações escaláveis.

---

## 🎯 Objetivo do Módulo

- Compreender a história e a evolução do Java
- Configurar corretamente o ambiente de desenvolvimento
- Entender o funcionamento da JVM, JDK e JRE
- Dominar os fundamentos da linguagem Java
- Aplicar estruturas de controle e lógica de programação
- Preparar o ambiente para projetos Java profissionais

---

## 📚 Cursos Concluídos

- **Introdução ao Java e seu Ambiente de Desenvolvimento**
- **Fundamentos da Linguagem de Programação Java**
- **Estruturas de Controle em Java**

---

## 🧠 Conteúdos Estudados

### 🔹 Introdução ao Java
- Apresentação da linguagem
- História e evolução do Java
- Ecossistema Java e mercado
- Funcionamento da JVM

### 🔹 Configuração do Ambiente Java
- Instalação do JDK (Oracle e Amazon Corretto)
- Configuração de variáveis de ambiente

- Questionário prático de configuração

### 🔹 Gerenciadores de Build
- Conceito de gerenciadores de dependências
- Introdução ao Maven
- Introdução ao Gradle
- Importância do build automation no backend

### 🔹 IDEs e Primeiro Programa Java
- Instalação e uso do IntelliJ IDEA
- Instalação e uso do VS Code
- Execução do primeiro programa Java
- Estrutura básica de um projeto Java
