# Módulo 02 – Introdução ao Java

Este módulo faz parte do **Bootcamp Accenture – Desenvolvimento Java & Cloud (DIO)** e tem como foco a construção da base técnica da linguagem Java e do ambiente de desenvolvimento.

---

## 🎯 Objetivo

- Compreender os fundamentos da linguagem Java
- Configurar corretamente o ambiente de desenvolvimento
- Aplicar lógica de programação e estruturas de controle
- Preparar o terreno para Programação Orientada a Objetos

---

## 📚 Cursos Concluídos

- Introdução ao Java e seu Ambiente de Desenvolvimento  
- Fundamentos da Linguagem de Programação Java  
- Estruturas de Controle em Java  

---

## 🧠 Conteúdos Praticados

- História e funcionamento do Java (JVM, JDK, JRE)
- Configuração do ambiente Java
- Uso de IDEs (IntelliJ e VS Code)
- Tipos primitivos e keywords
- Operadores aritméticos, lógicos e bitwise
- Estruturas condicionais (`if`, `switch`)
- Estruturas de repetição (`for`, `while`, `do while`)
- Introdução ao Git e GitHub

---

## 📈 Aprendizados

Este módulo consolidou a base necessária para o desenvolvimento backend com Java, permitindo evoluir com segurança para Programação Orientada a Objetos e projetos mais complexos.
