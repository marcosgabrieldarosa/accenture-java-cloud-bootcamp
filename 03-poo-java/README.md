# Módulo 03 – Programação Orientada a Objetos em Java

Este módulo faz parte do bootcamp **Accenture – Desenvolvimento Java & Cloud (DIO)** e tem como foco o aprofundamento da **Programação Orientada a Objetos (POO)** em Java, evoluindo do conceito à aplicação prática em cenários reais.

O conteúdo aborda desde a modelagem de classes até o uso de recursos avançados da linguagem, preparando a base para projetos mais robustos e profissionais.

---

## 🎯 Objetivo do Módulo

Consolidar os fundamentos e práticas da POO em Java, desenvolvendo a capacidade de:

- Modelar domínios de forma clara e coesa
- Aplicar corretamente os pilares da POO
- Utilizar recursos modernos da linguagem Java

---

## 🧠 Conteúdos Estudados

### 🔹 Abstração, Classes e Encapsulamento
- Criação e estruturação de classes
- Encapsulamento de atributos e comportamentos
- Uso de `records`
- Exercícios práticos de fixação

### 🔹 Herança e Polimorfismo
- Relações de herança
- Sobrescrita e sobrecarga de métodos
- Uso do `instanceof`
- Aplicação de polimorfismo em cenários reais

### 🔹 Interfaces e Expressões Lambda
- Interfaces e contratos de comportamento
- Interfaces funcionais
- Uso de lambdas
- Keywords mais utilizadas no contexto funcional

### 🔹 Collections e Classes Utilitárias
- List, Set e Map
- Tipos primitivos e Wrappers
- Classes `String`, `StringBuilder` e `StringBuffer`
- Uso de `BigDecimal`, `Enum` e `Optional`

### 🔹 Streams, Generics e Datas
- API de Streams
- Generics
- Classes de data e hora (`LocalDate`, `LocalDateTime`, `OffsetDateTime`, etc.)
- Comparação entre APIs legadas e modernas

### 🔹 Concorrência
- Classe `Thread`
- Interface `Runnable`
- Introdução ao conceito de execução paralela

### 🔹 Tratamento de Exceções e Debug
- Exceptions em Java
- Debugging
- Boas práticas no tratamento de erros

### 🔹 Gerenciamento de Dependências
- Maven
- Gradle
- Criação e configuração de projetos
- Comparação e migração entre ferramentas

---

## 🛠️ Prática e Aplicação

O módulo combina:
- Aulas teóricas
- Exercícios práticos
- Questionários
- Um **desafio de código prático**, onde os conceitos de POO são aplicados em um domínio estruturado

👉 O desafio de código possui **README próprio**, detalhando a implementação e evoluções aplicadas.

---

## 📌 Aprendizado Principal

Este módulo reforçou que Programação Orientada a Objetos vai além de criar classes:
> trata-se de **modelar problemas reais de forma clara, extensível e sustentável**.

O foco foi entender **quando e por que aplicar cada conceito**, criando uma base sólida para projetos Java mais avançados.
